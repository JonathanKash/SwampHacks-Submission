# Lineage — project context for Claude Code

Hackathon project (SwampHacks XII, UF, Oct 16-18 2026; Devpost closes Sun Oct 18 08:00 ET).
Read SPEC.md for the spec, PLAN.md for status and evaluation history, docs/DEMO.md for the
demo runbook. Optimize for a reliable live demo. Repo: github.com/JonathanKash/SwampHacks-Submission.

## What it does
Reconstructs the edit family tree of a pool of images (and paragraphs): asymmetric cost(a -> b)
("how cheaply is b a lossy function of a") over candidate pairs, then a minimum spanning
arborescence. Every decision carries evidence and an empirically calibrated precision.

## Stack and commands
- Python 3.13 backend in `backend/`, venv at `.venv/` (Windows: `.venv/Scripts/python`).
- Tests: `.venv/Scripts/python -m pytest backend/tests -q` (136); frontend `npm --prefix frontend run test -- --run` (9)
- Eval: `backend/scripts/gen_chains.py --name runN --seed S`, `backend/scripts/eval.py data/synthetic/runN`,
  `backend/scripts/calibrate.py <runs...>` (writes `backend/lineage/calibration.json`).
- API: `.venv/Scripts/python -m uvicorn app:app --app-dir backend --port 8010` (8000 is taken on the dev
  machine). Frontend: `cd frontend && npm run dev` (proxies to 8010) or `npm run build`; FastAPI serves
  `frontend/dist` with SPA deep links. Use `npm --prefix <abs path>` when running from elsewhere.
- Config and secrets: `.env` (see `.env.example`); tunables in `backend/lineage/config.py`.
- Deploy: `deploy/` (Dockerfile, docker-compose with Caddy auto-HTTPS, README).

## Hard rules
- Keep the cost terms and the Edmonds algorithm readable with short "why" comments; judges
  will ask about every part. All cost weights/thresholds stay in config.py.
- The engine must never read an item's true parent. Truth lives only in generator output /
  the upload record and is used by the eval and accuracy endpoint.
- Verdicts are never "guesses": every decision ships with evidence and a margin; precision
  claims come only from calibration.json (synthetic chains + per-corpus "web-memes" column: show both
  numbers). Pairwise verdicts return "inconclusive" when the direction rests on a symmetric cue.
  Do not present precision for text.
- Measure before keeping a cost change: eval on run1 (tuned) AND run2/run3 (held out); revert
  anything that lowers held-out accuracy. Record rejected experiments in PLAN.md.
- No secrets in code. `.env` only; keep `.env.example` current.
- Simple, readable code; prefer a few files over many. Every new library/API goes into the
  README credits. Keep the README "AI disclosure" honest (Claude, Codex, Gemini).
- Commit after each working step; gate commits on the build/test exit code, not on grep.
